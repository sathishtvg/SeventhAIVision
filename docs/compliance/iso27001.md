# ISO 27001:2022 Controls Mapping — Seventh AI Vision

**Standard:** ISO/IEC 27001:2022 (Information Security Management Systems)  
**Scope:** Seventh AI Vision platform — backend API, AI worker pipelines, web dashboard, mobile app, Kubernetes/Docker infrastructure  
**Last reviewed:** 2026-07-02

This document maps each ISO 27001:2022 Annex A control to the relevant platform capability. Controls marked **[CUSTOMER]** are the deploying organisation's responsibility and are not implemented in the software.

---
